sayeon-uploader 개인정보처리방침 (Privacy Policy)

시행일: 2026년 9월 23일

1. 앱의 목적

sayeon-uploader는 운영자 본인이 소유한 유튜브 채널(사연극장TV, 케미부장TV 등)에 본인이 제작한 영상을 업로드·예약 공개하고, 본인 영상의 댓글 게시와 채널 통계 조회를 자동화하기 위한 개인용 도구입니다. 일반 사용자를 대상으로 하는 서비스가 아닙니다.

2. 이용하는 Google 사용자 데이터

  • YouTube Data API: 본인 채널의 영상 업로드, 공개 시각 설정, 메타데이터(제목·설명·썸네일) 수정, 본인 영상의 댓글 작성
  • YouTube Analytics API: 본인 채널의 조회수·시청시간 등 통계 조회(읽기 전용)

3. 데이터의 보관과 공유

  • 인증 토큰과 통계 데이터는 운영자 본인의 컴퓨터에만 저장되며, 외부 서버에 전송·보관하지 않습니다.
  • 어떠한 Google 사용자 데이터도 제3자에게 판매·공유·양도하지 않습니다.
  • 광고 목적이나 다른 서비스의 학습 목적으로 사용하지 않습니다.

4. 권한 철회

Google 계정의 서드파티 앱 액세스 관리에서 언제든지 이 앱의 접근 권한을 철회할 수 있으며, 철회 시 로컬에 저장된 토큰은 더 이상 사용할 수 없습니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API로부터 받은 정보의 사용 및 이전은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
